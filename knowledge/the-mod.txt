=========================================================
Procedural Horse Coats: github.com/9-7-8/Procedural-Horse-Coats. A Minecraft (NeoForge)
mod with Mendelian horse genetics and generated coats. Code MIT, art CC BY-SA 4.0.

WHAT THE MOD KEEPS FOR ITSELF
Painting the coat, the order genes are applied in, per-copy inherited strengths (its
"epigenome"), game items, how big an effect is in game numbers, and every magical gene.
None of that belongs here.

WHAT THE MOD NEEDS THIS REPO NEVER TO BREAK
- The mod saves every horse as text: gene key = allele id / allele id. A changed allele id
  makes saved horses fail to load. A reordered allele list misaligns saved per-copy data.
  So: allele ids and their order are permanent. Append only.
- mod-map.json pins, per locus, the mod's key and the allele order it requires.
  "mod_only_alleles" lists alleles the mod has that are deliberately not here (the
  vampiric allele on the five body loci).
- Until piece 3 ships, nothing in the mod reads this folder. It is a mirror.

WHERE THINGS ARE IN THE MOD, IF YOU NEED TO LOOK
- Natural genes are Java classes:
  common/src/main/java/com/example/horsegenetics/common/genetics/genes/
- The registry: .../genetics/Genes.java
- Breeds, already JSON: common/src/main/resources/horsegenetics/breeds/
- Each gene's wiki page: wiki/gene-<name>.html, with Gameplay, Coding and Science tabs.
- The mod has its own rules file (CLAUDE.md) and procedures. They govern work in THAT
  repo, not this one.
